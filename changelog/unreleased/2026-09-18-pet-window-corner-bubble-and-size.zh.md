# 桌面宠物改到右下角，并补上透明、大小设置、动作与对话气泡

- **Date:** 2026-09-18
- **Type:** feature
- **Scope:** `desktop`, `server`, `web`

[English](2026-09-18-pet-window-corner-bubble-and-size.md)

悬浮的 Petdex 桌宠现在与被移植的参考实现一致：停在右下角、自身不画任何背景、有动作、大小可调，并用对话气泡汇报所跟踪会话的进展。

## 窗口

- 默认位置改为主显示器工作区的右下角（留 24px 边距），并 clamp 到已知显示器内。原先默认在左上角，会盖住应用自己的标题栏，看起来像「什么都没出现」。
- 窗口改为内容驱动尺寸：页面通过新增的 `pet:resize` IPC 上报自己需要多大，外壳**固定右下角**，于是气泡出现时窗口向左上方生长，而不是把宠物顶出它所在的屏幕边角。尺寸限制在最小 64px、最大 360×240。
- 在 Windows 上，`resizable: false` 会让窗口的最小尺寸跟随当前大小，导致 `pet:resize` 只能放大——气泡能出现却收不回去。外壳在每次 resize 调用期间临时放开 resizable，从而把这个最小值重新钉到新尺寸上。
- `pet:open` 不再对已打开的窗口重新套用保存的位置。那样会撤销用户尚未松手的拖拽，也会破坏 resize 的锚定。
- 拖拽改由渲染进程处理（pointer 事件 + `pet:move`），松手后的位置现在会写回 `petWindowPosition`。此前位置从未持久化，所以每次重启宠物都会回到默认角落。

## 透明

- 宠物页会给 `<html>` 打上 `linsight-pet-host`，样式表在该 class 下去掉全局不透明的 `body` 背景。Electron 窗口本来就是透明的；那块不透明的 body 才是宠物背后的白色底板。

## 大小

- 宠物占地从 192×208 降到 96×104，并新增 `petWindowScale` 偏好（0.5–2，默认 1）来缩放。设置 → 应用 提供 小 / 中 / 大 三档。
- 当放大后的宠物加上气泡会超过外壳 360px 上限时，气泡会收窄而不是溢出。

## 动作

- 走马灯周期的时长改由 mood 对应的 CSS class 决定，不再使用图集自带的帧节奏。idle 行的 6 帧 × 1100ms 是一个 6.6 秒的循环，看上去就是一张静止图。
- 每个 mood 在走马灯之外还叠加一个形变动画——待机时呼吸、工作时上下顿、悬停时弹跳、拖拽时左右摆动——并且拖拽会切到奔跑行并区分方向。

## 对话气泡

- 新增 `PetBubble`，显示所跟踪会话的标题、状态行（`待机` / `工作中` / `整理上下文`）以及助手最新输出的末尾，裁剪为两行。
- 活动桥的载荷从 `{ mood, timestamp }` 扩展为携带 `state`、`title`、`output` 与宠物外观，因此聊天窗口同时也是宠物或大小变更抵达浮窗的通道——第二个 Electron 窗口自己的偏好拉取只在挂载时跑一次。
- 任务结束后气泡会保留 6 秒，让最后一行输出可读，然后隐藏。

## 兼容性

- `petWindowScale` 是新的 `ui_prefs` 键；缺失或为 `null` 表示使用默认大小，已有数据无需迁移。
