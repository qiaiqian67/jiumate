# 智能体列表改为可浏览的网格

- **Date:** 2026-10-13
- **Type:** feature
- **Scope:** `web`

[English](2026-10-13-agents-grid.md)

智能体页面原本把每个 Agent 渲染成一条整行宽度的横条：名称、id、描述、
七个计数、一条迷你折线，再跟四个按钮。每一行都占满页面宽度，于是这一页读
起来像电子表格，很难从中挑出一个 Agent。

现在改为三列网格，手机上一列，上方是轮播的推荐位和分类筛选条。

## 网格

卡片改为纵向：头像、名称、版本、id、描述、计数、操作。`auto-rows-fr` 让
同一行的卡片等高，且不需要测量任何东西——该行取最高的一张，其余拉伸对齐，
所以一条长描述不会再让旁边的卡片底部参差。

折线图去掉了。在卡片宽度下它要么挤掉旁边的文字，要么溢出这一列；而一张
被压缩到能放下的图，说的话比它所依据的会话数还少。

## 搜索与分类

标题行里的搜索框按显示名、id **和**描述过滤。id 是因为配置和命令里引用
Agent 用的就是它；描述是因为两个名字相近的 Agent，真正的差别在那里。

分类胶囊**由 Agent 自身推导**——取带命名空间的 id 前缀（`team:writer` →
`team`）。`AgentSummary` 上没有分类字段，所以一份写死的胶囊列表就是第二份
真相，会和它所过滤的数据逐渐脱节；而为没有任何 Agent 拥有的分类准备胶囊
是死路。它们横向滚动而不换行：换行会把网格往下推一行，而这一行的高度还会
随列表变化。

搜索和胶囊**只**过滤网格。推荐位仍然从整个项目取——它是在展示存在的东西，
一个正在推荐被页面隐藏掉的 Agent 的面板，比没有面板更糟。

「没有匹配的 Agent」现在和「没有 Agent」区分开了：前者是筛选把它排除了，
后者是项目里确实没有。

## 推荐位

一次展示一个 Agent，每六秒轮换一次，也有箭头可以手动切换。箭头只在多于一个
时才出现——一对动不了的控件是失效的入口。

## 没有丢任何东西

原来那一条上有的每个控件现在都在卡片上：新会话、设置、用量、删除，计数仍然
深链到对应的设置页签。内置 Agent 仍然不提供删除。内核更新胶囊移到标题下方
独占一行，因为卡片宽度下它没有余地放在名称旁边，而压缩名称的代价更大。

## 一个测试抓不到的错字

网格的 class 写成了 `lg:grid-cols3`——少一个连字符。Tailwind 没有这个类，
于是被静默丢弃：规则什么也没做，而**那个 class 一直还在 DOM 里**。断言
class 字符串会通过。

它只因为有人去问了浏览器 `gridTemplateColumns` 才暴露出来——要三列，回来
两条轨道。测试现在断言完整的 class 字符串**并**否定那个错字，验证环节读的是
计算值。

web 2073 全绿。
